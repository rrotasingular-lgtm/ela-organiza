## 📋 Funcionalidades

- Cadastro de clientes
- Registro de serviços realizados
- Registro de valores
- Histórico de serviços
- Controle financeiro
- Consulta por cliente
- Relatórios
- Backup dos dados
- Funcionamento em dispositivos móveis e computador

## 📱 Como funciona

O Ela Organiza é uma WebApp que pode ser acessada pelo navegador e instalada na tela inicial do celular, proporcionando uma experiência semelhante à de um aplicativo.

A aplicação foi pensada para ser leve, simples e fácil de usar.

## 🔐 Privacidade

O projeto prioriza uma abordagem Local First, mantendo os dados no dispositivo sempre que possível.
